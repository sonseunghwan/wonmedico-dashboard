# 원메디코 경영 대시보드

매출 원장(.xlsx)과 재고현황(.xlsx)을 Supabase에 적재하고, GitHub Pages로 서비스하는 정적 대시보드입니다.

## 구성

- `index.html`, `css/`, `js/` — 프론트엔드 전체 (빌드 과정 없는 순수 HTML/CSS/JS)
- Supabase (Postgres + Auth + Edge Functions) — 데이터/인증/관리자 기능 백엔드
- 프론트엔드에는 공개용 publishable key만 포함되어 있으며, 실제 데이터 접근은 로그인한 사용자에게만 허용됩니다 (RLS)

## 기능

- **종합 / 매출 분석**: 기간별 매출 추이, 제품·거래처·담당자별 랭킹, 급성장/급감 품목, 고객 집중도 분석
- **재고현황**: 창고별 재고, 유통기한 임박 알림, 판매 속도 기반 재주문 알림, 추정 재고자산 가치
- **데이터 업로드** (관리자 전용): 매출/재고 엑셀 파일을 그대로 업로드하면 중복 없이 반영
- **계정 관리** (관리자 전용): 새 계정 생성 및 권한 관리 (Supabase Edge Function을 통해 서버에서 안전하게 처리)

## 데이터 갱신

관리자 계정으로 로그인 후 "데이터 업로드" 메뉴에서 엑셀 파일을 그대로 올리면 됩니다. 전체 파일이든 새로 추가된 부분만이든 상관없이 이미 등록된 거래/날짜는 자동으로 건너뜁니다.
